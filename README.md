# 🏦 Bank Account Management System

A simple **Bank Account Management System** developed in Python using **Object-Oriented Programming (OOP)** concepts.

This program allows users to check their balance, deposit money, withdraw money, and view transaction history through a menu-driven interface.

## 📌 Features

* 💰 Balance Inquiry
* 💵 Deposit Money
* 💸 Withdraw Money
* 📜 Transaction History
* ❌ Exit the Program
* ✅ Checks for invalid deposit and withdrawal amounts
* ✅ Prevents withdrawal when the balance is insufficient

## 🛠️ Technologies Used

* **Python**
* **Object-Oriented Programming (OOP)**
* Class and Objects
* Constructor (`__init__`)
* Methods
* Lists
* Conditional Statements
* Loops
* User Input

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the Project

Open the project folder in **VS Code** or any Python-supported IDE.

### 3. Run the Program

Open the terminal and run:

```bash
python bank.py
```
